# Аренда БЕЗ — fullstack-прототип Sprint 1

Адаптивный React + Express + tRPC проект по Figma Prototype и приложенному Sprint 1. Реализованы каталог в двух городах, реальные иллюстративные фото, интерактивная карта с резервным режимом, backend-заявки и авторизация по одноразовому коду.

## Локальный запуск

Требуются **Node.js 22+** и **pnpm 10+**. После клонирования или распаковки проекта выполните из корня:

```bash
pnpm install
pnpm dev
```

Приложение будет доступно по адресу, который выведет сервер, обычно `http://localhost:3000`.

| Команда | Назначение |
|---|---|
| `pnpm dev` | Запускает Express, tRPC и Vite в режиме разработки. |
| `pnpm test` | Запускает unit-тесты server auth и OTP-утилит. |
| `pnpm check` | Выполняет TypeScript-проверку без генерации файлов. |
| `pnpm build` | Собирает production-версию в `dist/`. |
| `pnpm start` | Запускает собранный production bundle. |

## Маршруты

| Путь | Сценарий |
|---|---|
| `/search` | Каталог Казани или Санкт-Петербурга: URL-фильтры, выбор города в шапке, список, карта и пустой результат. |
| `/listing/:id` | Карточка объекта: галерея, условия, стоимость, сервисный сбор и backend-заявка. |
| `/rent` | Информационный лендинг для арендатора. |
| `/landlords` | Лендинг для собственника с интерактивным калькулятором выгоды. |
| `/auth?mode=login` | Запрос и подтверждение одноразового кода. |
| `/auth?mode=register` | Регистрация с подтверждением одноразового кода. |
| `/owner` | Демонстрационная сводка объекта и заявок владельца. |

## OTP и заявки

Заявка на просмотр сохраняется в таблице `applications` через tRPC. OTP-челлендж хранит только хэш кода с TTL 5 минут, ограничивает повторную отправку 60 секундами и число попыток; сессия создаётся в HTTP-only cookie и очищается при выходе.

При локальной разработке без `SMSRU_API_ID` интерфейс показывает тестовый код. В production без ключа внешнего провайдера код не выдаётся и не отправляется. Для реальной SMS-доставки добавьте защищённую переменную `SMSRU_API_ID` и согласуйте имя отправителя в кабинете SMS.RU.

## Карта и изображения

Каталог использует Google Maps через встроенный proxy. Если внешняя карта недоступна, отображается автономная интерактивная схема с кликабельными маркерами и масштабированием; выбор квартиры не блокируется. Реальные фото в карточках — иллюстративные материалы Unsplash/Pexels, не фотографии конкретных предложений.
