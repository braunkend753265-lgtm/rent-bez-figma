# Аренда БЕЗ — frontend-прототип Sprint 1

Адаптивный React-проект по Figma Prototype и приложенному Sprint 1. В проекте реализованы видимые public-маршруты: поиск квартиры, детальная карточка, лендинги арендатора и собственника, формы входа/регистрации и демонстрационный кабинет владельца.

## Локальный запуск

Требуется **Node.js 22+** и **pnpm 10+**. После клонирования или распаковки проекта выполните команды из корня:

```bash
pnpm install
pnpm dev
```

Приложение будет доступно по адресу, который выведет Vite, обычно `http://localhost:3000`.

| Команда | Назначение |
|---|---|
| `pnpm dev` | Запускает локальный сервер разработки. |
| `pnpm test` | Запускает unit-тесты доменной логики поиска и калькулятора. |
| `pnpm check` | Выполняет TypeScript-проверку без генерации файлов. |
| `pnpm build` | Собирает production-версию в `dist/`. |
| `pnpm start` | Запускает собранный production bundle. |

## Маршруты

| Путь | Сценарий |
|---|---|
| `/search` | Каталог квартир: URL-фильтры, карта/список, доступность и пустой результат. |
| `/listing/:id` | Карточка объекта: галерея, условия, стоимость, сервисный сбор и анкета заявки. |
| `/rent` | Информационный лендинг для арендатора. |
| `/landlords` | Лендинг для собственника с интерактивным калькулятором выгоды. |
| `/auth?mode=login` | Клиентское состояние входа. |
| `/auth?mode=register` | Клиентское состояние регистрации. |
| `/owner` | Демонстрационная сводка объекта и заявок владельца. |

## Прозрачные ограничения

Это **frontend-поставка**, поэтому SMS/OTP, хранение персональных данных, KYC, модерация, договоры, платежи, реальные показы и менеджерский SLA не реализованы и не имитируются как работающие сервисы. Все формы завершаются явным демонстрационным статусом без отправки данных.

Матрица Figma ↔ Sprint 1 находится в `docs/figma-sprint-1-traceability.md`, а результаты технической проверки — в `docs/validation.md`.
