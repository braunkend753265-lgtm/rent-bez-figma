# Аренда БЕЗ — fullstack-проект Sprint 1

**Аренда БЕЗ** — адаптивная платформа поиска квартир, реализованная по Figma-макету и утверждённому Sprint 1. Проект объединяет React-клиент, Express-сервер, tRPC API и MySQL-схему для заявок и OTP-сценария.

## Что реализовано

| Область | Результат |
|---|---|
| Каталог | Поиск квартир в Казани и Санкт-Петербурге, список, карта, карточки и экран объекта. |
| Поиск | URL-синхронизированные фильтры по бюджету, комнатам, площади и доступности. |
| Избранное | Локальное сохранение объектов, toast-уведомления и компактный режим просмотра избранного. |
| Карта | Адаптер Yandex Maps с маркерами; без API-ключа включается интерактивная резервная схема. |
| Заявки | Создание заявок через tRPC с серверной валидацией и состояниями интерфейса. |
| Авторизация | OTP с TTL, rate limit, хэшированием одноразового кода и HTTP-only сессией. |

Подробный состав выполненной работы и известные ограничения приведены в [docs/WORK_COMPLETED.md](docs/WORK_COMPLETED.md).

## Предварительные требования

Для локальной разработки нужны **Node.js 22+** и **pnpm 10+**. Для Docker-сборки нужен Docker Engine; готовая конфигурация находится в файле [`for_you_Egor`](for_you_Egor).

## Локальный запуск

Установите зависимости и запустите development-сервер из корня проекта:

```bash
pnpm install
pnpm dev
```

Адрес приложения выводится в терминал, обычно это `http://localhost:3000`.

| Команда | Назначение |
|---|---|
| `pnpm dev` | Запускает Express, tRPC и Vite в режиме разработки. |
| `pnpm check` | Выполняет TypeScript-проверку без генерации файлов. |
| `pnpm test` | Запускает unit-тесты доменной логики, избранного, OTP и сессии. |
| `pnpm build` | Собирает frontend и server bundle в `dist/`. |
| `pnpm start` | Запускает готовую production-сборку. |
| `pnpm db:push` | Генерирует и применяет миграции Drizzle к настроенной базе. |

## Docker-сборка

Файл [`for_you_Egor`](for_you_Egor) является Dockerfile с нестандартным именем. Это сделано намеренно: он предназначен для локальной или внешней Docker-сборки и **не заменяет** управляемую конфигурацию публикации проекта.

```bash
docker build -f for_you_Egor -t rent-bez:local .
docker run --rm -p 3000:3000 --env-file .env rent-bez:local
```

Создайте локальный `.env` самостоятельно и не добавляйте его в Git. Для функциональных server-сценариев требуются системные переменные, в том числе `DATABASE_URL` и `JWT_SECRET`. Необязательные интеграции: `SMSRU_API_ID` для реальной отправки SMS и `VITE_YANDEX_MAPS_API_KEY` для живого слоя Yandex Maps. При их отсутствии приложение сохраняет тестовый OTP-режим и автономную карту.

> Docker Engine в текущей среде разработки отсутствует, поэтому локальная Docker-сборка должна быть запущена на машине с установленным Docker. Конфигурация проверена структурно, а production-сборка проекта проверена командой `pnpm build`.

После отправки в `main` GitHub Actions самостоятельно выполняет `docker build -f for_you_Egor` и smoke test контейнера через HTTP. Workflow можно также запустить вручную во вкладке **Actions** репозитория.

## Маршруты

| Путь | Сценарий |
|---|---|

## Подход к документации и проверке

Документация поддерживается вместе с исходным кодом: в ней фиксируются артефакты, команды запуска, переменные окружения, ограничения внешних интеграций и результаты проверок. Оригинальные материалы Sprint 1 и Figma не изменяются; связь требований с экранами зафиксирована в [`docs/figma-sprint-1-traceability.md`](docs/figma-sprint-1-traceability.md).

Каждое изменение проверяется последовательно: TypeScript (`pnpm check`), unit-тесты (`pnpm test`), production-сборка (`pnpm build`) и визуальная проверка desktop/mobile сценариев. Это позволяет отделять исходные данные и реализованную логику от результатов сборки и не выдавать непроверенные предположения за готовый функционал.

## Безопасность и ограничения

Одноразовые коды хэшируются, действуют ограниченное время и не сохраняются в открытом виде. Секреты и `.env` не включаются в репозиторий. Без внешних ключей SMS и Yandex Maps доступны безопасные тестовые/резервные сценарии, но отправка настоящих SMS и загрузка картографического слоя не выполняются.
