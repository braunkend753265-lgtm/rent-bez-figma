## Исправление контекста сборки

После того как локальная папка `node_modules` стала доступной Git, Docker workflow превысил лимит в 15 минут при передаче лишнего build context. Для исключения локальных зависимостей, кэшей, логов и VCS-данных добавлен `.dockerignore`. Зависимости устанавливаются внутри образа командой `pnpm install`, поэтому на работоспособность контейнера это не влияет, а объём входного контекста существенно сокращается.
