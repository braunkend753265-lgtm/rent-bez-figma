# Отчёт о выполненной работе — «Аренда БЕЗ»

## Краткий итог

В проекте реализован адаптивный fullstack-прототип сервиса аренды квартир по Figma-макету и требованиям Sprint 1. В результате доступен локально запускаемый React + Express + tRPC проект с каталогом, карточками недвижимости, фильтрами, картой, избранным, OTP-сценарием и backend-заявками.

## Методика выполнения и источники

Работа велась по трём взаимосвязанным источникам: Figma Prototype, утверждённому файлу Sprint 1 и обязательной контентной выгрузке. Оригинальные входные материалы не изменялись. Для каждого функционального изменения выполнялись TypeScript-проверка, unit-тесты, production-сборка и визуальная сверка интерфейса на desktop и mobile.

| Артефакт | Роль в работе |
|---|---|
| Figma Prototype | Визуальная композиция, маршруты и сценарии экранов. |
| Sprint 1 | Пользовательские истории, приоритеты и критерии приёмки. |
| Контентная выгрузка | Канонические тексты, свойства объектов и значения интерфейса. |
| `docs/figma-sprint-1-traceability.md` | Связь требований с маршрутами и сценариями. |

## Реализованный функционал

| Блок | Выполненная работа |
|---|---|
| Адаптивный интерфейс | Раздельные mobile и desktop-компоновки каталога, карточки объекта, лендингов и авторизации. |
| Города и каталог | Выбор Казани и Санкт-Петербурга в header, синхронизация URL, выдачи и центра карты; 9 объектов в доменной модели. |
| Поиск | Текстовый поиск и синхронизированные с URL фильтры: бюджет, комнаты, площадь, доступность и срок аренды. |
| Панель поиска | Отдельная кнопка «Бюджет» с быстрыми диапазонами и кнопка «Фильтры» для комнат, площади и доступности; избранное вынесено в компактный элемент. |
| Избранное | Добавление с карточки и детального экрана, `localStorage`, toast-обратная связь, режим только избранных. |
| Карта | Адаптер Yandex Maps, маркеры объектов, кликабельные переходы, loading/error-state и автономная схема без ключа. |
| Заявки | tRPC-процедура создания заявки и база `applications` с отображением результата в UI. |
| OTP | Нормализация телефона, хэширование кода, TTL 5 минут, rate limit 60 секунд, ограничение попыток и HTTP-only сессия. |
| Визуальные материалы | Реальные интерьерные иллюстрации в постоянном asset-хранилище, hover/focus и reduced-motion состояния. |

## Техническая реализация

| Уровень | Решение |
|---|---|
| Клиент | React 19, TypeScript, Tailwind CSS 4, Wouter. |
| Сервер | Express 4 и tRPC 11. |
| Данные | Drizzle ORM и MySQL; таблицы `users`, `applications`, `otp_challenges`. |
| Тесты | Vitest: доменная логика, URL-фильтры, избранное, OTP и logout. |
| Сборка | Vite собирает клиент; esbuild создаёт server bundle в `dist/`. |

## Ограничения и следующие настройки

В текущем состоянии внешний ключ Yandex Maps не подключён: каталог использует автономную интерактивную резервную карту. При добавлении `VITE_YANDEX_MAPS_API_KEY` адаптер загрузит настоящий слой Yandex Maps. Без `SMSRU_API_ID` OTP работает в безопасном тестовом режиме; для отправки настоящих SMS необходимо настроить учётные данные SMS.RU и имя отправителя.
