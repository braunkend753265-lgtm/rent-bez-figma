# Desktop-корректировка по Figma

## Принцип

Desktop — не увеличенный mobile. Все правила ниже применяются от `min-width: 961px`; мобильные правила и текущая mobile-компоновка остаются нетронутыми.

| Маршрут | Подтверждённая desktop-композиция Figma | Исправление |
|---|---|---|
| `/search` | Canvas 1171 px; выдача около 65% ширины, карта около 35%; шесть маленьких карточек в сетке 2×3; footer всегда завершает экран. | Установить сетку `1.8fr 1fr`, добавить шестой объект и footer. |
| `/listing/:id` | Canvas 1171 px; горизонтальная галерея `2/3 + 1/3`; текстовая колонка около 2/3, sticky summary около 1/3; footer. | Увеличить sidebar, закрепить desktop-правила и добавить footer. |
| `/rent` | Широкий белый лендинг: hero 2 колонки, 4 выгоды в ряд, 4 шага в ряд, светлое сравнение и light CTA. | Убрать dark CTA на desktop, довести преимущества до 4, добавить footer. |
| `/landlords` | Широкий белый лендинг: hero 2 колонки, 4 выгоды, 3 шага, расчёт 2 колонки, light CTA с фото. | Убрать dark/green CTA на desktop, довести преимущества до 4, оставить 3 шага и добавить footer. |
| `/auth` | Фон #F7F7F7, без public header, центрированная белая card шириной около 300 px, логотип находится внутри card. | В desktop скрыть header, уменьшить card, скорректировать vertical placement. |
| `/owner` | Figma не показывает desktop-кабинет. | Сохранить текущую responsive-сводку как согласованный extension, не использовать её как эталон для Figma-fidelity. |

## Acceptance criteria

Desktop-снимок `/search` при ширине 1280 px не содержит пустого пространства под выдачей до footer; картовая колонка заметно уже выдачи. Desktop `/rent` и `/landlords` не используют тёмные полноширинные CTA. Desktop `/auth` не отображает общую header-навигацию. Mobile 375 px остаётся визуально неизменным.
