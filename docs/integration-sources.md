# Источники интеграционных материалов

## OTP-провайдер

Для будущей production-интеграции выбран адаптер SMS.RU: официальный API принимает номер, сообщение и `api_id`, рекомендует JSON-ответ и предупреждает об обязательной защите формы от флуда с помощью CAPTCHA. Реализация в приложении будет ограничивать частоту запросов на сервере, хранить только хэш кода с TTL и не передавать ключ на клиент. [1]

## Yandex Maps

JavaScript API Яндекс Карт предназначен для интерактивных карт в веб-приложениях, а официальный quick start требует получить и включить API-ключ перед созданием карты. Маркеры поддерживаются API как отдельные интерактивные объекты. Текущая реализация использует адаптер, который включает слой Яндекс Карт после добавления ключа и сохраняет автономную интерактивную схему как резервный режим. [2] [3]
