# Источники интеграционных материалов

## OTP-провайдер

Для будущей production-интеграции выбран адаптер SMS.RU: официальный API принимает номер, сообщение и `api_id`, рекомендует JSON-ответ и предупреждает об обязательной защите формы от флуда с помощью CAPTCHA. Реализация в приложении будет ограничивать частоту запросов на сервере, хранить только хэш кода с TTL и не передавать ключ на клиент. [1]
