# Проверка готового frontend-проекта

Проверка выполнена после согласования границы поставки: видимые Figma-маршруты и клиентские сценарии Sprint 1 без имитации серверных интеграций.

| Проверка | Результат | Деталь |
|---|---|---|
| Unit-тесты | Пройдены | `pnpm test`: 4 из 4 тестов; фильтрация по тексту, комнатам и доступности, а также расчёт сервисного сбора. |
| TypeScript | Пройдено | `pnpm check`: без ошибок. |
| Production-сборка | Пройдена | `pnpm build`: Vite и server bundle собраны успешно. |
| Desktop-верстка | Проверена | Просмотрены `/search`, `/listing/baumana-1`, `/rent`, `/landlords`, `/auth?mode=register`, `/owner` при 1280×720. |
| Mobile-верстка | Проверена | Те же ключевые маршруты просмотрены при 375×812. |
| Карта | Проверена | Локальная интерактивная схема карты с переходами на карточки; внешняя загрузка карты исключена, поэтому UX не зависит от внешнего ключа или сетевого ответа. |
| Доступность | Проверена вручную | Семантические заголовки, labels, `aria-*` для модального окна и меню, keyboard-фокус, Escape для закрытия меню, reduced-motion. |
| SEO-база | Реализована | Русский `lang`, route-level title/description, `robots.txt`, favicon и тематический `theme-color`. |

Production-сборка выдаёт стандартное предупреждение Vite о chunk больше 500 kB; сжатый JavaScript составляет 176.59 kB и остаётся в пределах установленного для стартового bundle бюджета 200 kB. Отложенная маршрутизация может быть добавлена как дальнейшая оптимизация, когда появятся реальные метрики загрузки.

## Desktop-корректировка

После повторного прохода desktop-фреймов Figma исправления изолированы в `@media (min-width: 961px)`. Проверены `/search`, `/listing/baumana-1`, `/rent`, `/landlords` и `/auth` при 1280 px; также `/search`, `/landlords` и `/auth?mode=register` при целевой ширине 1171 px. Отдельно повторно просмотрены mobile-маршруты `/search`, `/rent`, `/landlords` и `/auth` при 375 px. Финальные `pnpm test`, `pnpm check` и `pnpm build` прошли успешно.

## Сверка с приложенной выгрузкой

После получения `pasted_content.txt` канонические данные шести объектов, адреса, площади, этажи, рейтинги, число отзывов, цены и сервисные сборы были заменены на значения из выгрузки. Для desktop проверены `/search`, `/listing/baumana-1`, `/rent`, `/landlords` и `/auth?mode=login` при 1171 px. По отдельному mobile-проходу при 375 px проверены те же маршруты. Сценарий оценки квартиры владельцем использует desktop-only поле адреса и явный клиентский success-state без отправки данных.

## Fullstack, карта и города

Добавлены таблицы `applications` и `otp_challenges`, серверные tRPC-процедуры, проверяемые OTP-утилиты и HTTP-only сессия. Проверены `pnpm test`, `pnpm check` и `pnpm build`. Переключатель города в header синхронизирует каталог и URL для Казани и Санкт-Петербурга. Google Maps загружается через встроенный proxy; при сетевой ошибке отображается доступная локальная карта с кликабельными маркерами, поэтому сценарий выбора объекта не блокируется. Карточки используют новые реальные иллюстративные интерьерные фото, а hover-анимации отключаются для `prefers-reduced-motion`.
