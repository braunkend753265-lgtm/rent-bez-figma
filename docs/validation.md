# Проверка готового frontend-проекта

Проверка выполнена после согласования границы поставки: видимые Figma-маршруты и клиентские сценарии Sprint 1 без имитации серверных интеграций.

| Проверка | Результат | Деталь |
|---|---|---|
| Unit-тесты | Пройдены | `pnpm test`: 4 из 4 тестов; фильтрация по тексту, комнатам и доступности, а также расчёт сервисного сбора. |
| TypeScript | Пройдено | `pnpm check`: без ошибок. |
| Production-сборка | Пройдена | `pnpm build`: Vite и server bundle собраны успешно. |
| Desktop-верстка | Проверена | Просмотрены `/search`, `/listing/baumana-1`, `/rent`, `/landlords`, `/auth?mode=register`, `/owner` при 1280×720. |
| Mobile-верстка | Проверена | Те же ключевые маршруты просмотрены при 375×812. |
| Карта | Проверена | Локальная интерактивная схема карты с переходами на карточки; внешняя загрузка карты исключена, поэтому UX не зависит от внешнего ключа или сетевого ответа. |
| Доступность | Проверена вручную | Семантические заголовки, labels, `aria-*` для модального окна и меню, keyboard-фокус, Escape для закрытия меню, reduced-motion. |
| SEO-база | Реализована | Русский `lang`, route-level title/description, `robots.txt`, favicon и тематический `theme-color`. |

Production-сборка выдаёт стандартное предупреждение Vite о chunk больше 500 kB; сжатый JavaScript составляет 176.59 kB и остаётся в пределах установленного для стартового bundle бюджета 200 kB. Отложенная маршрутизация может быть добавлена как дальнейшая оптимизация, когда появятся реальные метрики загрузки.
