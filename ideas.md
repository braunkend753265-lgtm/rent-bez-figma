# Визуальная спецификация: реализация Figma

## Ground-truth reference

**Источник истины:** [Figma: Untitled, node 1-5098](https://www.figma.com/design/qdhHkjg3dUrbyoZT8Z1z5L/Untitled?node-id=1-5098&m=dev). Реализация должна воспроизводить предоставленный мобильный экран, а не создавать альтернативный дизайн.

**Выбранный фрейм:** `Owner page design (Copy)` — вертикальная мобильная страница шириной **402 px** и высотой **2996 px** на фоне `#F7F7F7`.

## Зафиксированные признаки макета

| Область | Наблюдение, обязательное для реализации |
|---|---|
| Продукт | Цифровая платформа «Аренда БЕЗ» для взаимодействия владельца жилья и арендатора. |
| Визуальный тон | Светлый, спокойный, структурированный интерфейс с нейтральным серым фоном, тёмным текстом и функциональным синим акцентом. |
| Компоновка | Узкая мобильная колонка, последовательность модулей: верхняя навигация, карточки/сводки, блок объявления с главным фото, действия и информационные секции. |
| Цвета | Основной фон `#F7F7F7`; ключевые текстовые оттенки `#222222` и `#6A6A6A`; интерактивный акцент `#2563EB`; светлые границы `#EBEBEB`. |
| Изображение | Карточка объявления включает главное интерьерное фото в исходном разрешении 1200 × 700. |
| Компоненты | В Figma обнаружены иконки `IconHome` (22 × 22 и 20 × 20), `IconGlobe` (13.99 × 13.99) и дополнительные иконки; использовать лаконичную линейную визуальную систему. |
| Адаптивность | Макет задан для мобильного экрана, но реализация должна корректно масштабироваться на планшет и desktop без поломки информационной иерархии. |

## Принцип реализации

При сомнении приоритет имеют **структура, визуальная иерархия, контентная плотность, размеры отступов и состояния компонентов из Figma**. Улучшения допустимы только для доступности, отзывчивости, семантики, производительности и рабочих интеракций — без изменения визуального характера исходника.

## Стиль в исходном коде

В каждом редактируемом компоненте и CSS-файле в начале должен быть краткий комментарий: «Figma fidelity: светлый мобильный интерфейс Аренда БЕЗ; нейтральный фон, синий акцент, плотные информативные карточки».
